# 🌱 AgroRed Hidalgo

Plataforma web para registrar, geolocalizar y conectar huertos familiares y mercantiles del estado de Hidalgo.
Proyecto Integrador 5° semestre ISC · **Equipo Nexosoft · ITSOEH**.

**Stack:** HTML5 · CSS3 · JavaScript · PHP 8 (PDO) · MySQL/MariaDB · Bootstrap 5 · Bootstrap Icons · Leaflet + OpenStreetMap · OSRM

➡️ Instalación paso a paso y explicación completa: **[docs/GUIA_INSTALACION.md](docs/GUIA_INSTALACION.md)**

Inicio rápido (XAMPP): copia la carpeta a `htdocs/`, importa `database/schema.sql` y `database/seed.sql` en phpMyAdmin y abre
`http://localhost/agrored-hidalgo/`. Usuario de prueba: `mario.cordero@ejemplo.com` / `Agrored2026!`
